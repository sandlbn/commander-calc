\textbf{Commander Calc Reference Manual}\\
Release 1.0

\vspace{10pt}

This manual describes \ccprod{} as it is built from the source in
\fname{x16sheet/}. Where the manual and the program disagree, the program is
right and the manual is wrong; please say so.

\vspace{10pt}

The program is distributed as seventeen files: \fname{CMDRCALC.PRG} and
\fname{OVL1.BIN} through \fname{OVL16.BIN}. All seventeen must be present on the
same device and in the same directory. Appendix~\ref{app:files} lists them.

\vspace{10pt}

\ccprod{} runs on a Commander X16 with 512K of banked RAM and a CMDR-DOS
storage device at unit 8, and on the \fname{x16emu} emulator with an equivalent
configuration. Chapter~\ref{ch:installing} gives the details.

\vspace{16pt}

\textit{Commander X16} is the name of the computer this program was written
for. \textit{Lotus}, \textit{1-2-3} and \textit{Excel} are named in this manual
only where the behaviour of \ccprod{} is being compared with theirs; they are
the trademarks of their respective owners and this program is not connected
with, endorsed by or derived from any of them.
